# Blogen

Modern English blog theme for HTMLy. Mobile-friendly magazine layout powered by Tailwind CSS.

## Features

- Responsive, mobile-first layout (sticky header, drawer menu, search overlay)
- **Tailwind CSS** (CDN) with a sky accent palette
- **Outfit** typeface
- Magazine-style post list with date column and fluid typography
- Safe-area padding for notched phones
- Optional widgets: tags, post nav, recent/popular posts, tag cloud

## Activate

Admin → Config → Blog theme → **Blogen**
